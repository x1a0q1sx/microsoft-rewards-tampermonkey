# Microsoft Rewards Tampermonkey 助手

一个用于 Microsoft Rewards 的 Tampermonkey 用户脚本，提供搜索、活动、每日连续打卡和阅读任务的辅助执行功能。

> 本项目为个人学习与自动化研究项目。Microsoft Rewards 的规则和接口可能随时变化，请自行评估使用风险，并遵守 Microsoft 服务条款。

## 功能

- PC 搜索和移动搜索任务
- Rewards 活动任务辅助执行
- “每日连续打卡活动”侧边栏及子活动卡片点击
- 阅读任务
- 活动跨页面恢复
- 活动标签页完成后自动关闭
- 活动失败最多重试 3 次
- 搜索达到设定次数后自动暂停 1 分钟
- 悬浮窗显示关键运行日志

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)。
2. 打开 Tampermonkey 管理面板。
3. 新建脚本，或直接将 `Get_Microsoft_Rewards_fixed.user.js` 拖入浏览器。
4. 保存并启用脚本。
5. 打开 [Microsoft Rewards](https://rewards.bing.com/)，确认右侧出现脚本悬浮窗。

也可以直接打开脚本文件，选择使用 Tampermonkey 安装。

## 使用

登录 Microsoft Rewards 后，在 Rewards 页面使用悬浮窗中的功能按钮：

- “搜索”：执行搜索任务。
- “活动”：执行可识别的活动任务。
- “一键全部执行”：按脚本流程执行搜索、活动及其他任务。

首次使用建议先手动观察一次运行过程，确认账号地区、任务类型和浏览器行为符合预期。

## 定时自动执行

油猴脚本不能脱离浏览器直接运行。若需要用青龙面板、Windows 任务计划程序或系统定时器触发，建议让定时任务启动 Edge 并打开：

```text
https://rewards.bing.com/?mr_auto_run=1
```

脚本检测到 `mr_auto_run=1` 后，会自动点击悬浮窗中的“一键全部执行”。浏览器窗口需要保持打开，脚本会在页面内继续执行。

青龙面板相关文件与教程位于：[qinglong/README.md](qinglong/README.md)。

如果 Edge 打开 Rewards 页面时下载 `Clear.PNG`，通常是下载类扩展拦截了微软埋点资源。优先在 `edge://extensions` 中临时禁用“迅雷下载支持”等下载扩展；这类扩展可能会干扰页面脚本注入。

## 配置

脚本中的配置位于 `CONFIG` 对象，例如：

```js
pause: {
    enabled: true,
    interval: 10,
    duration: 60 * 1000
}
```

当前默认设置为每完成 10 次搜索后暂停 1 分钟。活动失败时最多尝试 3 次（首次执行加 2 次重试）。

## 搜索额度说明

`PC x/y` 和 `移动 x/y` 不是固定值，Microsoft 会根据账号地区、浏览器客户端、登录态和每日完成情况返回不同计数器。

- PC 搜索：Edge 通常能看到浏览器侧 `PCSearch` 计数器；Chrome 不一定有同样额度。脚本会先尝试 Rewards API 和 Bing Flyout，仍拿不到计数器时会显示“无搜索额度”。
- 移动搜索：多数情况下需要 Bing 移动端 App 或真实移动端场景，桌面浏览器不能可靠完成。
- 每天 0 点后额度重置。如果之前有、现在没有，先看是否已经完成，或刷新 Rewards 仪表板确认当日进度。
- 新版脚本会输出一行 `搜索额度：PC ... | 移动 ... | 来源 ...`，可用于判断是微软没返回，还是浏览器/地区限制。

## 常见问题

如果提示 `invalid_grant: The provided value for the 'code' parameter is not valid`，说明这次授权码已经失效、已被消费，或旧版本把它重复编码了。请先升级到最新版本，然后在悬浮窗里重新点击「获取授权码」完成一次新授权。旧授权码是一次性的，不能刷新或重复使用。

## 注意事项

- 脚本依赖 Microsoft Rewards 页面结构和接口，页面改版后可能需要调整。
- 不要在多个浏览器标签页同时执行同一批任务，以免任务状态互相覆盖。
- 自动打开的活动标签页会在完成后尝试关闭；如果浏览器阻止关闭，请手动关闭。
- 网络异常、登录状态失效、地区限制或任务本身不可用，都可能导致活动失败。
- 不要将账号 Cookie、访问令牌、日志截图或个人信息提交到公开仓库。
